## Speak 1.0

Speak is ready for its first stable release.

### Dictation that stays on your computer

- Record with a configurable global shortcut and paste the result into the active app.
- Choose between local speech models, including fast streaming models with a live overlay.
- Keep transcription history, custom vocabulary, language and audio-device settings in one place.

### Meetings and projects

- Record and transcribe meetings, then search and organize them in projects.
- Import supported audio, video and chat sources for processing inside Speak.
- Recover safely from interrupted work and damaged local history data.

### Release reliability

- Startup failures now show an actionable error instead of disappearing silently.
- Update checks report failures clearly and signed release updates use the Speak release channel.
- Packaging, audio capture, clipboard output, migrations and the main user flows are covered by automated release checks.
